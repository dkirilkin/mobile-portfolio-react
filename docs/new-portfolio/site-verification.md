# Проверка основной версии сайта

Объём и подтверждённые ограничения — `site-rollout.md`. Локальный production-сервер: `http://localhost:3002/`.

- `npm run build` — успешно: основные страницы и совместимые перенаправления собраны.
- `npm run lint` — успешно.
- `git diff --check` — успешно.
- `site-check.mjs` / `site-checks.json`: 12 основных страниц на ширинах 320, 390, 768 и 1440 px; 48 наблюдений, ошибок нет. На каждой странице один заголовок h1, одна общая навигация и один footer; горизонтального переполнения нет; канонические ссылки указывают на основные URL, noindex отсутствует.
- Восемь страниц приложений содержат прежний ProjectCarousel; проверены прокрутка, листание в увеличенном просмотре и Escape.
- Оба кейса содержат «Как устроена система», «Задача», «Результат» и «Приложения кейса». Все пять связей зарядки и шесть связей доставки сохранены.
- Проверены переходы приложение → кейс → приложение, шесть прежних URL, работа каталога без JavaScript и ответы 404 для скрытого и отсутствующего контента.
- Сверка с `main`: все исходные тексты и системные связи в `src/data/cases.ts` сохранены. Отличия — два утверждённых названия и подтверждённый личный вклад в зарядку.

Первая попытка снимков остановлена из-за ожидания decode для ленивых изображений вне видимой части карусели. Повторная съёмка использует загруженные изображения; это исправление процедуры съёмки, а не приложения. Проверка canonical первоначально различала равнозначные адреса главной со слешем и без; сравнение исправлено через URL.href, сохранённые наблюдения проверены повторно.

Impeccable detector запущен один раз. Он выдал advisory-замечания о размерах шрифта, отсутствующих в сокращённой шкале frontmatter DESIGN.md; текущая типографика сохранена согласно утверждённому шаблону. Это не результат повторного выбора дизайна.

Снимки основных страниц и отдельных секций: `site-*.png`. Браузер — Chromium / Edge; физические устройства и WebKit в эту проверку не входят. Публикация не выполнялась.

Финальный независимый визуальный вердикт: `ship`. Существенных проблем не обнаружено; дополнительных правок интерфейса не требуется. Проверены соответствие принятому шаблону, сохранность карусели, материалов, структуры и личного вклада. Движение и клавиатура проверены браузерным сценарием выше; reviewer рассматривал предоставленные снимки и исходники.
