У клиента — адрес.
У техника — маршрут.

Клиент заказывает зарядку. Техник получает маршрут и выполняет заказ. Два приложения — внутри одной сервисной системы.

Моя работа — разработка приложений клиента и техника на Flutter + Supabase.

Два взгляда
на одну услугу

Один человек ждёт зарядку автомобиля. Другому нужно пройти маршрут и выполнить заказ. У каждого — собственное приложение.

Локация, параметры услуги и статус заказа.

За пределами двух приложений

Диспетчерская и OCPP-брокер — связанные компоненты большой системы. Здесь показан контекст их взаимодействия, а не моё авторство.

  1. КлиентОформляет заказ
  2. ДиспетчерНазначает техника
  3. ТехникВыполняет маршрут
  4. OCPP-брокерУправляет зарядкой
