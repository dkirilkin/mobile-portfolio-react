# Проверки первого результата

Дата: 7 сентября 2026. Проверены исследовательские HTML-эскизы; это не аудит завершённой новой версии сайта.

## Выполнено

- Chromium / Microsoft Edge, headless: ширины 320, 390, 768 и 1440 px для каждого из трёх направлений.
- На 12 комбинациях нет горизонтального переполнения, ошибок JavaScript и незагруженных изображений. Машинный отчёт: `browser-checks.json`.
- Визуально просмотрены первые экраны для телефона и десктопа, скриншоты кейсов и внешние референсы. Сохранены полные страницы для телефона, планшета и десктопа.
- Страница сравнения и HTML-отчёт проверены при 390 и 1440 px: переполнения нет; все внутренние ссылки страницы сравнения возвращают успешный ответ. Просмотр изображения после исправления скрытого диалога повторно проверен.
- Проверены кнопки этапов/ролей, изменение изображения, открытие просмотра исходника, закрытие Escape, возврат фокуса и выбор кнопки клавишей Enter.
- При prefers-reduced-motion плавная прокрутка отключается; переходы CSS тоже отключены. Основной текст и изображения видны сразу и находятся в исходном HTML.
- Изображения вписаны с сохранением пропорций. Клиентские промослайды не выдаются за чистые скриншоты. Крупный просмотр предоставляет оригинальный файл.
- Golos Text, Oswald и Prata загружаются локально; русские переносы просмотрены на тестовых ширинах.
- `npm run build` — успешно, 16 статических страниц существующего Next.js-проекта.
- `npm run lint` — успешно после перевода вспомогательных исследовательских скриптов на ES modules.
- Исходные `src/`, `public/`, package.json и lock-файл не изменены. Добавлены только PRODUCT.md и docs/new-portfolio в ветке codex/portfolio-new-direction.

## Детектор impeccable

Запущен один раз после подготовки эскизов. Выдал предупреждения: линия маршрута ошибочно распознана как декоративная граница скруглённой карточки; отсутствие src у закрытого диалога просмотра; повышенная частота тире в направлении В. Изображение закрытого диалога получило реальный исходный src. Линия маршрута имеет смысловую функцию, скруглённой карточкой не является. Замечание о тире — стилистическое, не ошибка работоспособности.

## Ограничения проверки

Это проверка responsive viewport в настольном Chromium, не испытание на физических iPhone/Android и не проверка WebKit. Фактическое касание на телефоне, screen reader, полевые Core Web Vitals и производительность production-версии предстоит проверить после выбора и реализации направления. PNG показывают статичные состояния; намеченные анимации линии/разворота пока не реализованы.

Ссылки на магазины сверены с доступными публичными страницами: клиент в App Store и Google Play, техник в Google Play. Telegram-ссылки в эскизах ведут на адрес из репозитория; доступность самого профиля внешней проверкой не подтверждена. Сообщения не отправлялись. Web-demo магазина не тестировалось на оплату; в материалах оно остаётся демонстрацией.

Локальные ресурсы эскизов отдаются без внешних CDN и библиотек анимации. Это снижает зависимость от сети, но не заменяет будущую проверку LCP/INP/CLS и оптимизацию финальных шрифтов и изображений. Страница сравнения намеренно содержит больше изображений, чем будущая главная портфолио.
