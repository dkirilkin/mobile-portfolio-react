# Навигация и структура после уточнения пользователя

Восстановлена структура старого портфолио в выбранном оформлении: на главной отдельно кейсы и самостоятельные работы; в шапке — «Кейсы» и «Работы»; каталог содержит восемь видимых проектов. Два кейса открываются на отдельных страницах, связываются с приложениями и доступны через обратные ссылки. Скрытые проекты остаются скрытыми.

Данные приложений, их порядок, видимость, описания и демо-доступ переиспользованы из общего `Project`. Кейс зарядки сохраняет уточнённые границы личного вклада. Исходные публичные маршруты не изменены.

Проверено на production-сервере localhost:3002:

- `npm run build` — успешно, 29 статических страниц, включая новые маршруты.
- `npm run lint` и `git diff --check` — успешно.
- `navigation-check.mjs`: 12 страниц × 4 ширины (320, 390, 768, 1440), HTTP 200 и отсутствие горизонтального переполнения.
- Реальные переходы: главная → кейс → приложение → кейс → главная → все работы → проект.
- Просмотр скриншота с клавиатуры и возврат фокуса после Escape.
- Восемь ссылок на работы без JavaScript; скрытый Cognitivy и неизвестный проект возвращают 404.
- Ошибок JavaScript нет. Визуально проверены главная, каталог, блок работ и описание проекта на телефоне и десктопе. Устранён сдвиг стрелки в мобильной строке работы.

Результаты: `navigation-checks.json`; снимки: `navigation-*.png`. Ранние отчёты прототипа описывают предыдущую стадию до восстановления навигации.
