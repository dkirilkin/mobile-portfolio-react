# Проверка прототипа «Крупный план»

7 сентября 2026. Проверяемая область: `/preview` и `/preview/charging`.

Пользователь выбрал направление В для всего портфолио. Главная содержит пять работ; подробный кейс на этом этапе реализован для зарядки. Роль «Разработчик мобильных приложений» остаётся рабочей формулировкой. Исходные публичные маршруты сохранены, публикация не выполнялась.

## Автоматические и браузерные проверки

- `npm run build`: успешно, включая оба новых маршрута.
- `npm run lint` и `git diff --check`: успешно после финальных изменений.
- Impeccable detector: `[]` для новых страниц и компонентов, один запуск.
- Production-сервер: `http://localhost:3002`.
- `prototype-check.mjs`: две страницы × ширины 320, 390, 768 и 1440 px. HTTP 200, горизонтальное переполнение 0, ошибок браузера 0.
- Проверены открытие и закрытие изображений, удержание и возврат фокуса, Escape, переключение клиента/техника, reduced motion, переходы к работам и возврат из кейса.
- Без JavaScript на главной доступны заголовок, пять работ и контактные ссылки.
- `prototype-capture.mjs`: шесть видов (десктоп, планшет и телефон для обеих страниц). Перед съёмкой выполнены прокрутка и загрузка изображений; отсутствующих изображений 0.

Подробные результаты: `prototype-checks.json`, `prototype-capture.json`. Снимки: `prototype-home-*.png`, `prototype-charging-*.png` и отдельные фрагменты работ.

Проверки выполнены в Chromium / Edge с эмуляцией размеров экрана. Физические устройства и WebKit в эту проверку не входили.
