Используй скилл **redesign-existing-projects** и проведи редизайн этого проекта (Next.js + React + TypeScript + Tailwind, App Router). Пройди полный цикл скилла: Scan → Diagnose → Fix. Сначала покажи мне список найденных проблем (Diagnose), потом приступай к правкам.

## Дайлы (design-taste-frontend)

- `DESIGN_VARIANCE: 8` — асимметрия, экспериментальный layout, без центрированных hero-секций
- `MOTION_INTENSITY: 8` — скролл-анимации, spring-физика, staggered entry; магнитные эффекты только через `useMotionValue`/`useTransform`, без `useState` в анимациях; всё, что выше 3, оборачивай в `prefers-reduced-motion`
- `VISUAL_DENSITY: 4` — просторно, много воздуха, это портфолио, а не дашборд

## Цвета

- Базовый акцент — **оранжевый**. Подбери оттенок с насыщенностью ниже 80% (без кислотного оранжевого) и построй вокруг него полную палитру: нейтралы одной температуры (тёплые серые), off-black вместо чистого `#000`, тонированные тени в цвет фона.
- Один акцентный цвет. Остальные убери. Никаких purple/blue «AI-градиентов».
- Светлая и тёмная секции не должны случайно мешаться — выбери единый тон страницы или осознанную систему.

## Адаптивность

- Верстай **mobile-first**: базовые стили — для мобильных, дальше расширение через `md:` (планшет) и `lg:`/`xl:` (десктоп).
- Проверь каждую секцию на трёх форматах: телефон, планшет, десктоп. Асимметричные и broken-grid раскладки на мобильном должны грациозно складываться в одну колонку, а не ломаться.
- `min-height: 100dvh` вместо `100vh` для полноэкранных секций.

## Шрифты и кириллица

Контент сайта — на русском, поэтому подходят только шрифты **с полной кириллической поддержкой** (включая `ё`, `₽`, тире, кавычки-ёлочки). Это отсекает часть рекомендаций скилла: Cabinet Grotesk, Satoshi, Outfit кириллицу **не поддерживают**.

- Хорошие варианты с характером и кириллицей: **Unbounded** (дисплейный, для заголовков), **Manrope**, **Onest**, **Golos Text**, **Raleway** (текстовые).
- Текущий Geist кириллицу поддерживает — можно оставить его как текстовый и добавить характерный дисплейный шрифт для заголовков.
- Проверь, что выбранный шрифт имеет нужные начертания (Medium/SemiBold) именно в кириллице — у некоторых шрифтов кириллица есть только в Regular/Bold.
- Заголовки: крупные, с отрицательным letter-spacing; учти, что русские слова в среднем длиннее английских — проверь переносы и `text-wrap: balance`.

## Ограничения проекта

- Соблюдай правила из AGENTS.md: не хардкодь контент в компоненты, используй общую модель `Project` ([src/types/project.ts](src/types/project.ts)), повторяющиеся секции выноси в переиспользуемые компоненты.
- Не ломай существующий функционал, не мигрируй на другой стек. Правки — точечные и ревьюабельные.
- Работу веди в текущей ветке `feature/ai-positioning` или создай отдельную ветку `feature/redesign` от `dev`.

## Порядок работ

Следуй Fix Priority из скилла: шрифты → палитра → hover/active-состояния → layout/отступы → замена дженерик-компонентов → состояния (loading/empty/error) → финальная типографская полировка.
